KVII CLOUD 2.0 — комплект сервера Windows и Android-проекта

СЕРВЕР WINDOWS
1. Распакуйте папку windows-server на ноутбук.
2. Запустите START_SERVER.bat.
3. При первом запуске разрешите PowerShell доступ в частных сетях Windows Firewall.
4. Файлы облака хранятся в windows-server\KVII_CLOUD на диске ноутбука.
5. Сервер показывает физические диски ПК через /api/disks.

ANDROID
Откройте папку android-project в AndroidIDE/Android Studio и соберите APK.
Приложение ищет сервер широковещательным UDP-запросом (порт 45454).
Телефон и ПК должны быть в одной Wi-Fi сети. В настройках роутера не должно быть включено
изоляции клиентов (AP/client isolation).

ФУНКЦИИ
- поиск сервера и список файлов;
- загрузка файлов в папку KVII_CLOUD на ПК;
- информация о дисках ПК: занято, свободно, общий объём;
- меню файла: открыть по HTTP, поделиться, скачать, удалить с ПК.

ВАЖНО ПРО ПАМЯТЬ ТЕЛЕФОНА
Открытие файла передаёт его приложению-просмотрщику по HTTP и может зависеть от типа файла.
Поделиться файлом требует временной копии в кэше Android; она не является постоянным хранилищем.
Команда «Скачать» сохраняет файл в выбранное пользователем место телефона.

API
GET  /api/list
GET  /api/disks
POST /upload?name=имя_файла
GET  /view?name=имя_файла
GET  /download?name=имя_файла
POST /api/delete?name=имя_файла

Безопасность: сервер предназначен для доверенной домашней Wi-Fi сети. Не открывайте порт
8765 в интернет и не используйте публичные/гостевые сети. Авторизация в этой версии отсутствует.
